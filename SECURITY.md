# Security Policy

## Report a vulnerability privately

Do not disclose suspected vulnerabilities, exploit details, credentials, personal
data, or customer information in a public GitHub issue.

Use GitHub's **Report a vulnerability** function on the Security tab of this
repository when available. If it is unavailable, contact the repository owner
privately through the GitHub profile and clearly mark the message **Security**.

Include:

- affected product, version, and macOS version;
- impact and affected security boundary;
- minimal reproduction steps;
- logs with secrets and personal data removed; and
- any suggested mitigation.

Please allow reasonable time to investigate and prepare a fix before public
disclosure. Acknowledgement and remediation timing depend on severity,
reproducibility, and release constraints. No bounty program is currently offered.

## Public support

Non-sensitive bugs and support requests belong in the
[public request forms](https://github.com/buusmorten/documentation/issues/new/choose).
