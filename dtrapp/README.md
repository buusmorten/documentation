## Product summary

The app provides live radio streaming, Now Playing metadata, song history,
program information, podcast links, saved tracks, program reminders, private
listening statistics, widgets, Live Activities, and iCloud synchronization where
available.

Product behavior depends on the current app version, iOS/iPadOS version, device,
network connection, Apple services, and external station services.
