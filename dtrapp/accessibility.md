# DTRAPP Accessibility

Last updated: July 31, 2026

Den Tunge Radio uses native Apple interface and media controls and supports system
accessibility behavior such as VoiceOver labels, Dynamic Type where supported,
reduced-motion-aware effects, and system playback controls.

Report an accessibility barrier through the
[support form](https://github.com/buusmorten/documentation/issues/new?template=support.yml)
and select **Accessibility**. Include the device, OS and app versions, assistive
technology, affected screen, and expected behavior without adding private data.
