# DTRAPP Support and Feedback

Last updated: July 31, 2026

## Get help

Use the [public support form](https://github.com/buusmorten/documentation/issues/new?template=support.yml)
for questions, non-sensitive bug reports, accessibility feedback, and feature
requests. A free GitHub account is required. You may also contact
`morten@noget.org` for support that should not be posted publicly.

Include the app version, iOS/iPadOS version, device model, whether the issue occurs
on Wi-Fi and mobile data, the affected screen, and the exact non-sensitive error.

Never publish Apple Account information, notification contents, private listening
history, saved-track lists, CloudKit data, access tokens, or screenshots containing
personal information.

## Quick troubleshooting

### Live audio does not start

1. Confirm another app or website can use the internet.
2. Try both Wi-Fi and mobile data where available.
3. Stop and restart playback.
4. Force-close and reopen Den Tunge Radio.
5. Check whether the station website is currently streaming.

### Program reminders do not appear

Open **Settings → Notifications → Den Tunge Radio**, allow notifications, then
enable program reminders inside the app. Focus modes and notification summaries may
delay presentation.

### Saved tracks do not synchronize

Confirm the device is signed into iCloud, iCloud Drive is available, and Den Tunge
Radio has iCloud access. Local saving continues when iCloud is unavailable; cloud
synchronization may resume later.

### Widget or Live Activity is stale

Open the main app and start playback to refresh shared Now Playing information. iOS
controls widget and Live Activity update timing.

Security vulnerabilities must follow the repository [Security Policy](../SECURITY.md)
and must not be disclosed in a public issue.
