# Remote.Me Accessibility

Last updated: July 31, 2026

Remote.Me uses native macOS controls and supports keyboard navigation and standard
system appearance behavior where provided by macOS. The viewer can be resized after
opening at the negotiated display size.

## Report an accessibility issue

Use the [support form](https://github.com/buusmorten/documentation/issues/new?template=support.yml)
and select **Accessibility**. Include the Remote.Me and macOS versions, the assistive
technology in use, the affected screen or control, and the expected behavior. Do not
include sensitive screen content or personal information.

Accessibility feedback is treated as product feedback and prioritized by impact,
reproducibility, and release safety.
