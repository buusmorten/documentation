# CubeHarbor Privacy Policy

Last updated: July 30, 2026

CubeHarbor is developed by Morten Buus.

## Data Collection

CubeHarbor does not include advertising, analytics, tracking, or profiling
SDKs. The developer does not collect personal information through the app.

## Data Stored On Your Mac

CubeHarbor stores server profiles, preferences, console logs, downloaded server
packages, worlds, plugins, mods, player administration details, and exported
server descriptions locally on the user's Mac. This data is not uploaded to a
CubeHarbor service.

## Network Connections

CubeHarbor makes network connections for user-requested features, including:

- Checking server and runtime versions
- Downloading server packages or metadata from configured sources
- Opening third-party download and documentation pages
- Testing local Bedrock connectivity
- Listening for and forwarding Bedrock UDP traffic when forwarding is enabled

Third-party services process requests under their own privacy policies.

## Local Network

CubeHarbor requests local-network access for Bedrock discovery, connection
testing, and UDP forwarding between the Mac, local game devices, and a Bedrock
server running in a Multipass virtual machine.

The forwarding listener stops when forwarding is stopped, the server is
stopped, or CubeHarbor quits.

## Support Requests

Support requests are submitted through the public
[CubeHarbor support tracker](https://github.com/buusmorten/documentation/issues/new?template=support.yml).
Information submitted there is processed by GitHub and may be publicly visible.
Do not include passwords, access tokens, private player information, or public
IP addresses.
