# CubeHarbor Support

CubeHarbor is developed by Morten Buus.

## Request Support

To ask a question, report a bug, or request help, open a public support request
in the [CubeHarbor support tracker](https://github.com/buusmorten/documentation/issues/new?template=support.yml).
A free GitHub account is required to create a request.

Include:

- CubeHarbor version and build number
- macOS version
- Mac model and processor
- Server type and selected server version
- What you expected to happen
- What happened instead
- Relevant selectable console or update-log text

Do not include passwords, access tokens, private player information, or public
IP addresses.

## Troubleshooting Information

For server setup, update, Java, Multipass, or network problems:

1. Open CubeHarbor and select the affected server.
2. Enable **Nerd** mode.
3. Reproduce the problem once.
4. Copy the relevant console text into the support request.

For a launch problem, state whether the CubeHarbor dashboard, Dock icon, and
cube menu-bar control appear.

No account, subscription, license key, or in-app purchase is required to launch
or inspect CubeHarbor.
