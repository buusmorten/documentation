# Lattice-VM Documentation

Lattice-VM is an independent, open-source virtual machine manager for macOS, iOS,
iPadOS, and visionOS. It is derived from UTM and uses QEMU and Apple virtualization
technologies.

> **Developer preview:** Lattice-VM is early-stage software. There are currently no
> official binary releases, and it is not recommended as a replacement for a stable
> VM installation. Back up virtual machines before testing development builds.
