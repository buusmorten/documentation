# Lattice-VM Support and Feedback

Last updated: July 31, 2026

Lattice-VM is currently a source-based developer preview without official binary
releases or guaranteed end-user support.

For documentation feedback or a non-sensitive question, use the
[documentation support form](https://github.com/buusmorten/documentation/issues/new?template=support.yml).
For reproducible source defects and development proposals, use the
[Lattice-VM issue tracker](https://github.com/buusmorten/Lattice-VM/issues).

Before reporting a problem:

1. Confirm the current source revision and Apple platform version.
2. Identify the host hardware and guest architecture.
3. State whether the VM uses QEMU or Apple Virtualization.
4. Reproduce with a backed-up test VM.
5. Include sanitized logs and configuration details.

Never publish guest credentials, disk images, license keys, private network topology,
public IP addresses, personal data, or proprietary VM content.

Security vulnerabilities must follow [Security](security.md), not a public issue.
